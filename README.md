### \#UrbanCart Sales Performance Dashboard

# 

* Project Overview:



**UrbanCart Sales Performance Dashboard is an interactive Tableau dashboard created to analyze sales performance using data visualization techniques.**



* Objective:



**The objective of this project is to analyze sales, profit, quantity, category-wise performance, regional performance, product performance, and sales trends over time using Tableau.**



* Dataset:



**Dataset Name: UrbanCart Sales Dataset**



**Number of Records: 1,000**



**Source: Self-created / Synthetic Sales Dataset**



**Format: Excel (.xlsx)**



* Tools \& Technologies



**Tableau Desktop**



**Microsoft Excel**



**Data Visualization**



**Dashboarding**



* Dashboard Features:



**The dashboard includes:**



**Total Sales KPI**



**Total Profit KPI**



**Total Quantity KPI**



**Sales Trend Over Time**



**Sales by Category**



**Sales by Region**



**Top 10 Products by Sales**



**Interactive Year filter**



**Interactive Category filter**



**Interactive Region filter**



**Interactive State filter**



* Calculated Fields



**Total Sales = SUM(\[Sales])**



**Total Profit = SUM(\[Profit])**



**Profit Ratio = SUM(\[Profit]) / SUM(\[Sales])**



**Average Sales = AVG(\[Sales])**



* Key Insights



**Electronics generated the highest total sales among the categories.**



**South generated the highest total sales among the regions.**



**Lenovo IdeaPad Slim 3 was the highest-selling product by total sales.**



**The dataset contains 1,000 sales transactions.**



**Total sales were approximately ₹10.14 crore.**
